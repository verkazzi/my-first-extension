# my-first-extension

**Разработчик:** Зинурова Вероника
**Наименование расширения:** my-first-extension

## Краткое описание
Продукт представляет собой расширение (плагин) для среды разработки Visual Studio Code. Проект реализован в рамках выполнения лабораторной работы по созданию пользовательских дополнений. Основная задача расширения — интеграция новой пользовательской команды в интерфейс редактора.

## Функциональные возможности
* Регистрация новой команды `Hello World` в глобальной палитре команд VS Code.
* Вывод уведомления с текстом «Привет из моего первого расширения!» при активации команды.
* Логирование процессов запуска и остановки расширения в консоль отладки.

## Инструкция по запуску
Для локального тестирования и запуска проекта выполните следующие шаги:
1. Склонируйте исходный код проекта из удаленного репозитория на локальный компьютер.
2. Откройте терминал в корневой папке проекта и установите необходимые зависимости с помощью команды: `npm install`.
3. Выполните компиляцию TypeScript-кода: `npm run compile`.
4. Запустите режим отладки, нажав клавишу `F5` (откроется новое окно Extension Development Host).
5. В новом окне редактора активируйте палитру команд сочетанием клавиш `Ctrl + Shift + P` (для Windows/Linux).
6. Введите в поиске `Hello World` и выберите созданную команду для проверки работы плагина.
